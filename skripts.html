Skript tooling

Not everything deserves a plugin. These are the tools a live server runs on day to day — handing out crate keys, letting staff post as another player, printing the rules. Small surface, written to sit on top of the plugins rather than duplicate them.

The thread running through all three

Never duplicate what a plugin already owns. keys.sk could mint its own key items and doesn't — it calls KyronCrates and lets the plugin stay the only thing that decides what a valid key is. A script that reimplements a plugin's data format works right up until the day the plugin changes it.

Anything that can be abused gets logged. Handing out loot and speaking as another player are both things people argue about afterwards. Both write to their own file with who did it, to whom, and what was sent — because chat scrollback is not evidence.

Wrong input should teach you the right input. Run these with no arguments and you get the list of valid crates, or the list of online players — not a usage string and not an error. The most common reason staff mistype one of these is that they're half-remembering a name.
