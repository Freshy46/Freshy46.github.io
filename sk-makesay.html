makesay.sk

Posts a line in chat as though a named player typed it — with their real rank prefix, in their real colours, in the server's real chat format.

Skript1 commandLuckPermsaudit log

What it does

CommandWhoWhat it does
/makesay <player> <message>staffBroadcasts the message formatted as that player's chat line
/makesaystaffPrints the online players, with a count, so you can copy a name exactly

Used for running events in character, covering for a player who's dropped mid-scene, and staff announcements that need to come from a specific name rather than from the server.

Decisions

The formatting is the entire job

A fake chat line that doesn't match real chat isn't a fake chat line — it's an obviously fake chat line, and it gets spotted in under a second. Players read chat format as a shape long before they read the words in it. Wrong prefix spacing, a missing colour reset, the tag in the wrong place, and the illusion is gone.

So the script rebuilds the server's exact chat format rather than approximating it: rank prefix, then the player's name, then a colour reset, then the message. It reads the target's rank live from their LuckPerms group permission at the moment the command runs, so someone who was promoted an hour ago shows up with the right tag without anyone editing the script.

The rank checks are ordered deliberately, with the highest rank last so it overwrites everything below it. A player who holds several groups gets the one that outranks the others, which is what their real chat line would show.

Adding a rank is meant to be a one-line change

Each rank is a single line mapping a group to the prefix text it renders as, kept together in one clearly marked block with a comment explaining the ordering rule. Adding a new rank is copying one line and putting it in the right position.

The prefix strings have to match the chat plugin's configured output character for character, so the comment above the block also records how to look the exact text up rather than guessing at it. That note is the difference between the next person getting it right first time and them shipping a prefix that's one space off.

A tool that can put words in someone's mouth needs a paper trail

It's permission-gated, and every use writes a line recording who ran it, who it was attributed to, and the full message that went out.

Not because staff are expected to misuse it — because the first time a player insists they never said something, the log is the only thing that can settle it either way. Without one it's a staff member's word against a player's, and the tool becomes something you can't safely defend having on the server at all.

It runs from console as well as in game, so it works from a control panel during an event when nobody with permission is logged in.

No arguments prints the player list

The command needs an exact name, and exact names are the thing people get wrong — capitalisation, a number on the end, an underscore they don't remember. Running it bare prints everyone online with a count, so the name can be read off rather than guessed.

Leaving the message off gets a specific error saying the message is missing, rather than broadcasting an empty line under someone's name.
