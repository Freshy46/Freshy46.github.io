Working with me

Most of what's on this site started as someone asking for something that didn't exist yet. If you want a plugin built, the useful things to tell me first are which server software and version you're on, roughly how many players it needs to hold up under, and what the feature is meant to feel like to the person using it — the last one matters more than the spec.

I work on Paper 1.21 in Java 21, plus Skript for the smaller stuff, and I build the front-end side too when a server needs a store or a landing page to go with it. There's a review from someone I built a combat system for, if you want to know what that's like from the other side.
