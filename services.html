How I work

StepWhat happens
1 · TalkYou tell me what you want. Not a spec — what it should feel like to the player using it. I'll tell you honestly if it's a bad idea, or if a plugin that already exists does the job
2 · ScopeI come back with what I'd build, what's in and what's out, and a price. Nothing starts until you've agreed to both
3 · Demo earlyYou get something you can actually run and click as soon as there's anything worth showing, not at the end
4 · IterateYou play it, you tell me what's wrong, I change it. This is the part that makes the difference and I don't rush it
5 · ShipBuilt jar, config, and documentation written so your staff can actually use it

What you get

  • Documentation that isn't an afterthought. Every config option explained, including the ones where the obvious change is the wrong one.
  • Config you don't have to fight. Where it makes sense the setup lives in an in-game menu instead of a YAML file — KyronCrates has no config worth opening.
  • Built for a live server. Crash-safe, dupe-resistant, and tested against the awkward paths, not just the happy one.
  • Straight answers. If something will take longer than I said, you hear it from me first.

What it costs

I quote per job rather than publishing a rate card, because a rate card is wrong for almost every job. A one-command script and a system like AegisStaff aren't the same work and shouldn't cost the same. Tell me what you want and you get a number before anything starts — no hourly meter running, no bill that grows while you're not looking.

What moves the price, roughly in order of how much it matters:

WhatWhy it changes the price
SizeOne command that prints something is an evening. A system with its own database, GUIs and forty commands is not
StateAnything that has to remember something between restarts needs storage designing, and storage is where the hard bugs live
Custom itemsCustom models, textures or a resource pack is a separate piece of work from the plugin that uses it
InterfacesAn in-game editor is far more work than a config file, and far better to use. Worth it for anything an admin touches often
HostilityAn FFA or anarchy server needs dupe-resistance and crash-safety that a private SMP genuinely doesn't
IterationA fixed spec is cheaper than "build it and we'll see". Both are fine — say which you want

If the answer is that an existing free plugin already does what you need, I'll tell you that instead of quoting. It costs me a job and saves you money, and you'll come back for the thing that genuinely doesn't exist yet.

Paying

Full payment up front, once we've agreed the scope and the number. Nothing starts before that, and the price doesn't move afterwards unless you ask for something that wasn't in the scope.
