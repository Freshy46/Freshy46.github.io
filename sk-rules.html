rules.sk

The Spear SMP rules, printed in chat on demand. Deliberately boring, and one of the most-used commands on the server.

Skript1 command6 sectionsplayers + console

What it does

CommandWhoWhat it does
/rulesanyone with the permissionPrints all six rule sections into chat

Six numbered sections, each with a heading and its own rules underneath:

#SectionCovers
1RespectHarassment, discrimination, hate speech, toxicity and personal attacks
2CombatPvP is fully allowed; combat logging is an instant death
3Griefing & StealingGriefing is allowed — stated plainly so nobody argues it later
4CheatingHacks, X-ray, autoclickers, dupes, exploits and unfair mods — bannable
5Server PerformanceDeliberate lag machines and builds that hurt performance may be removed
6OtherReport bugs instead of abusing them; staff have the final say on anything not covered

Decisions

Written to survive a scrolling chat window

Chat is a hostile place to put a document. It scrolls, it's narrow, it has no headings, and anything longer than a few lines gets pushed off the top by whoever is talking. So the layout does the work that formatting normally would: a horizontal rule top and bottom to mark where the block starts and ends, a centred title, numbered headings with an icon on each, blank lines between sections, and bullets under the sections that carry more than one rule.

The result is something you can find the middle of after it's scrolled — a player looking for the combat rule can spot section 2 without re-reading from the top. That's the entire design goal.

The wording is the point, not the code

Rules only work if staff can point at the exact sentence during an argument, which means the text has to say precisely what it means. Rule 3 is a single line saying griefing is allowed, because a vaguer version invites a debate every time it comes up. Rule 6 explicitly covers loophole-hunting and gives staff the final say on anything unlisted, which is the clause that stops the other five being lawyered.

Keeping it in a script rather than in a pinned Discord message means it can be corrected and reloaded live, in the moment, without a restart and without anyone going to find the message.

Small things that make it behave like a real command

It carries a description and usage line, so it shows up properly in the server's help output instead of being an undocumented command people only know about by word of mouth.

It's permission-backed with its own denial message rather than the default one, and it runs from console as well as in game — so it can be fired from a control panel or a scheduled announcement, not just by a player typing it.
